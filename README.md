# موسیقی دلکش

سایت فارسی **موسیقی دلکش** یک پروژهٔ Hugo برای انتشار و سازمان‌دهی متن آهنگ‌ها و تصنیف‌های موسیقی ایرانی است.

## هدف پروژه

- ارائهٔ متن ترانه و تصنیف در یک ساختار قابل جست‌وجو
- دسته‌بندی آثار بر اساس خواننده، آهنگساز و ساختار موسیقی
- فراهم‌کردن پخش آنلاین و لینک دانلود برای آثاری که منبع صوتی آن‌ها در محتوا ثبت شده است
- نگه‌داشتن ادعاهای تاریخی و اطلاعات کتابشناختی در حدی که برای آن‌ها منبع کافی وجود داشته باشد

## فناوری

- **Hugo** — تولید سایت استاتیک
- **PaperMod** — پوستهٔ پایه
- **Vazirmatn / Lalezar** — فونت‌های محلی
- **GitHub Actions + GitHub Pages** — build و deployment

## ساختار محتوا

Taxonomyهای اصلی:

- `categories` — ساختارها و دستگاه‌های موسیقی
- `tags` — نام یا عنوان نمادین اثر
- `artists` — خواننده
- `composers` — آهنگساز

راهنمای جزئی‌تر مدل محتوا در [TAG_GUIDE.md](TAG_GUIDE.md) و قواعد ممیزی اطلاعات در [CONTENT_FACT_AUDIT.md](CONTENT_FACT_AUDIT.md) ثبت شده‌اند.

## توسعهٔ محلی

پس از نصب Hugo و دریافت submodule پوسته:

```bash
git submodule update --init --recursive
hugo server
```

برای build تولیدی:

```bash
hugo --gc --minify --baseURL "https://delkash-music.ir/"
```

خروجی `public/` تولیدی است و در Git دنبال نمی‌شود.

## سیاست محتوایی

اطلاعات مربوط به خواننده، آهنگساز، ترانه‌سرا، ساختار موسیقی و تاریخچهٔ اثر باید تا حد امکان بر اساس منبع قابل بررسی ثبت شوند. اگر یک ادعا منبع کافی ندارد، نباید به‌عنوان واقعیت قطعی در سایت نوشته شود.

همچنین پیش از انتشار یا بازنشر متن و فایل صوتی، وضعیت حقوق انتشار و منبع آن‌ها باید جداگانه بررسی شود؛ وجود یک فایل در مخزن به‌تنهایی به معنی داشتن مجوز انتشار نیست.
